# Your Potential — портфолио разработки

Распакуйте архив целиком и откройте `index.html`. Сайт работает без сборки: изображения и скрипты лежат рядом. Крюк на обложке ведёт к разделам: Дизайн, Проекты, Ещё немного..., Бонус, Контакты, затем строка-предложение для Kwork и Соц сети (пока пустые). Прежние разделы — галерея и три демо — сохранены в `backup/`. Кнопка FX переключает эффекты.

Для просмотра открыть `index.html` или выполнить `python3 -m http.server`. Для публикации на GitHub Pages разместить файлы в корне публикуемой ветки.

Сменяемые слова на обложке — картинки в `drafts cover/words` (вырезаны из `words-source.webp`), их порядок задаёт разметка, время показа — `words.js`.

Пиксельная анимация облаков и логотипа на обложке (`pixels.js`) читает пиксели изображения через canvas, поэтому работает только при открытии через сервер (`python3 -m http.server`, GitHub Pages). При открытии `index.html` напрямую с диска обложка остаётся статичной.

Проекты лежат в `projects/`: каждый в своей папке со своим `index.html`. Карточка проекта на главной — блок `.project` в разделе «Проекты», превью — `preview.png` в папке проекта. Первый проект — концепт-лендинг бюро загородных домов `projects/dysph-house/`.

Переключатель RU / EN — `i18n.js`. Русский текст берётся из разметки, английский перевод лежит в словаре `EN` в начале файла: новый текст на сайте нужно добавить туда (ключ — русская строка как на странице).
